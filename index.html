高度化PICS BLE ビューア

BLE信号機（高度化PICS）のアドバタイズを、Web Bluetoothで受信して可視化する受信専用ツール。送信・接続・信号機の操作はしません。

対応環境と受信の可否

環境を確認しています。

実機受信には、実験的な Web Bluetooth Scanning API に対応した Chrome と、chrome://flags/#enable-experimental-web-platform-features の有効化が必要です。HTTPS（または localhost）で開いてください。Safari / Firefox では実機受信はできません。iPhone・iPad では Safari だけでなく Chrome など他のブラウザも中身は WebKit のため、通常は実機受信できません。その場合はデモと16進テストで画面を確認できます。Mac では「システム設定 → プライバシーとセキュリティ → Bluetooth」で Chrome の許可も必要です。

仕様メモと注意

  • メーカーID 0x01CE（HOUWA SYSTEM DESIGN, k.k.）の manufacturerData をPICSとして扱います。
  • Type 0：交差点の識別名称（UTF-8、最大14バイト）。Type 1：緯度・経度（符号付き32ビット、除数 1,000,000）。Type 2：最大6灯の歩行者信号と残り値。
  • 信号は下位4ビットで 0:信号なし / 1:赤 / 2:点滅青 / 3:青 / 4:None と解釈します。残り値は上位4ビットが0〜7なら1を加えた値、8以上なら不明（—）とします。
  • 信号データを5秒以上受信できない場合は「更新なし」と表示し、点滅を止めます。停止後は「最終受信値」と明示します。
  • このアプリは受信専用です。青信号の延長や押しボタン操作などの送信機能はありません。

参考：警察庁「高度化PICS」、ble-pics-viewer（GitHub, MIT）の公開README、Chrome の Web Bluetooth Scanning / Watch Advertisements サンプル。UTMS協会の詳細規格は非公開のため、バイト位置の解釈は実機での検証が必要です。受信対象は公共インフラから不特定多数へ送信される公開電波で、個人を識別できる情報は含まれません。
